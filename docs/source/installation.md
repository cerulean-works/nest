# Install Nest

Nest requires Python 3.14 or later.

Install Nest from GitHub:

```bash
pip install "git+https://github.com/cerulean-works/nest.git@main"
```

A versioned release installation command will be provided when the first Early Access release is tagged.

For the shared Controller, connect to the authorized Tailscale network before
making remote calls. Hosts running their own Controller also need the
[deployment prerequisites](deploy).

Continue with [Run your first remote function](quickstart).
